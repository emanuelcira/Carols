Connect to GitHub

Saving changes needs a GitHub token that can edit the Carols repo. It is stored only on this device.

  1. Open GitHub token settings.
  2. Repository access: Only select repositories, then Carols.
  3. Permissions: Contents, set to Read and write.
  4. Generate, copy it and paste it here.
